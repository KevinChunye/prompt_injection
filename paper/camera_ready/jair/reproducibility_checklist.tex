\subsection*{Explanations on any of the answers above (optional):}

Design choices (all articles, item 5): the task family, payload wording and per-cell
sample sizes are described but not separately motivated (Section~\ref{sec:limitations}).
Code and data licenses: the benchmark code and the per-run log are released under the MIT
license (GitHub repository and Hugging Face dataset \texttt{kevinwhc/kill-chain-canaries}).
Unaggregated data: the per-run log covers every text-surface run, including one collected
batch not used in the paper's tables (marked \texttt{in\_paper = False}); for the PDF
relay only per-cell counts are released.
Randomness: models were queried at temperature 0 through provider APIs, which do not
guarantee deterministic outputs; canary tokens are drawn at random per run; the drift
classifiers use a fixed seed (42) in the released code.
Execution environment: the experiments call hosted model APIs (identifiers in
Section~\ref{sec:benchmark}); client software versions are pinned in the released
\texttt{requirements.txt}; local hardware does not affect the results.
Hyperparameters: model settings (temperature 0, 2048 max tokens) are reported; the
drift classifier settings (100 trees, depth 3) are in the released code; no
hyperparameter search was performed.
Statistics: we report Wilson 95\% confidence intervals for every rate instead of
hypothesis tests, and call results at $n=3$ directional.
Data sets: task content and injected payloads are generated by the released code; no
external data set is used in the reported runs.

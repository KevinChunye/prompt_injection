# TMLR submission

Anonymous version of the full paper (`../main.tex`) in the official TMLR style (`tmlr.sty`, `tmlr.bst`).
Generated by `../tools/make_venue_versions.py`; text, tables and numbers are unchanged.

- `main.pdf`: 15 pages (about 11 pages of body, then Broader Impact Statement, references, appendix).
- Rolling submission on OpenReview (TMLR); journal, no presentation or travel required.
- Double-blind. The arXiv preprint is allowed, but do not link to it from the submission.
- Overlap with non-archival workshop versions is allowed; it must not be under review at another
  archival venue (for example USENIX Security) at the same time.

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`
